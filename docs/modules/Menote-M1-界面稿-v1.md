## 一、登录页（未登录时的默认落地）

| 项 | 内容 |
|---|---|
| 块 | ① 品牌区（`BrandLogo` + 应用名）② 表单卡：用户名输入（`Field`）③ 登录密码输入（`Field`，`type=password`）④ 主操作按钮「登录」⑤ 注册入口（**仅当注册开关打开时显示**） |
| 主操作 | 「登录」——唯一实心主色按钮 |
| 空状态 | 不适用（表单页）。首次提交前的输入框为空是常态 |
| 错误 | 就地提示（字段下方）：统一文案「用户名或密码错误」；冷却时「尝试过于频繁，请 N 秒后再试」并禁用按钮；断网「无法连接服务器，请检查网络后重试」（**不进入离线模式**） |
| 键盘 | `Enter` 在任一输入框内提交（主操作 + Enter）；首屏焦点落在用户名 |
| M1 不做 | 记住我、第三方登录、忘记密码入口（需求明确无找回路径） |

## 二、注册页（库中无用户时直接显示）

| 项 | 内容 |
|---|---|
| 块 | ① 品牌区 ② 提示行「第一个注册的账号将成为管理员（owner）」（**仅库中无用户时**）③ 用户名 ④ 登录密码 ⑤ 再输一次登录密码 ⑥ 主操作按钮「注册」 |
| 主操作 | 「注册」 |
| 空状态 | 不适用 |
| 错误 | 用户名不合法/已占用 → 就地提示；注册未开放时该页不可达（直接访问提示「注册未开放」） |
| 键盘 | `Enter` 提交；焦点落在用户名 |
| 说明 | 密码两次不一致时就地提示；**不加密码强度条**（需求未要求，避免自造规则） |

## 三、主骨架（`AppShell`，登录后所有屏共用）

```
┌─────────────────────────────────────────────── 顶栏（54px，6 块） ────────┐
│ 品牌 │ 面包屑 │ 搜索框 │ 同步胶囊 │ 隐私胶囊 │ 账户头像 │
├──────────────┬──────────────────────────────────────────────────────────┤
│ 功能栏 294px  │ 主操作区                                                  │
│  ├ 新建按钮   │  ├ 左列 330px：条目列表                                   │
│  ├ 快速录入框 │  └ 右列 弹性：正文（编辑器 + 底部状态栏）                  │
│  └ 导航区(滚) │                                                          │
└──────────────┴──────────────────────────────────────────────────────────┘
```

| 块 | M1 的落地程度 |
|---|---|
| 顶栏 6 块 | 全部就位；**搜索框在 M1 只做占位**（不可输入，`title` 说明"M2 提供搜索"）；**隐私锁胶囊 M1 不显示**（未启用隐私锁，DESIGN.md §2.5/拆解 M02-05 都要求未启用时不显示） |
| 同步胶囊 | 三态：`已同步` / `上传中 N`（有待上传项时）/ `离线，改动会在联网后上传`；**队列为空时不显示计数** |
| 账户头像 | 圆形头像，字母取用户名首字；点击弹快捷菜单——**M1 只放「设置」与「退出登录」两项**（快捷菜单的可配置项属 M2/M18-03） |
| 功能栏 | 新建笔记按钮 + **快速录入框（M1 占位）** + 最简导航（全部笔记）；设置入口在头像菜单里。录入框按 DESIGN.md §2.5 的**三行结构与 136px 总高、导航 y=252 不变量一次到位**：输入区可输入、模式切换（Memo/待办/笔记）可切换且只换附加项内容不换高度；**发布按钮禁用并说明原因**（`title`：「发布功能将在 M2 提供」，DESIGN.md §6.1 要求禁用必须说明） |
| 左列条目列表 | 见「四」 |
| 右列正文 | 见「五」 |

主操作：**「新建笔记」**（功能栏顶部，M1 屏内唯一实心主色按钮）。

## 四、笔记列表（左列 330px）

| 项 | 内容 |
|---|---|
| 块 | ① 列表头（`ItemListHead`：标题「全部笔记」+ 条目数）② 列表行（`ItemRow`：标题、摘要一行、修改时间、同步状态小标记） |
| 主操作 | 无（主操作在功能栏的「新建笔记」） |
| 空状态 | （`EmptyState`）「还没有笔记」+ 出口：「点击左上角的新建笔记开始写」+ 一个「新建笔记」次操作按钮 |
| 交互 | 点条目**在右列直接打开**（禁止把侧滑详情接回列表，DESIGN.md 禁止项 #15）；键盘 `↑/↓` 移动选中、`Enter` 打开 |
| 排序 | 修改时间倒序；置顶（`pinned`）在前——M1 只渲染顺序，置顶开关属 M2 |

## 五、正文区（编辑器页）

| 项 | 内容 |
|---|---|
| 块 | ① 正文头（`DocHead`：可编辑标题输入 + `DocModeSwitch` 三档「分屏 / 仅编辑 / 仅预览」）② 正文区（`Editor` 或 `MarkdownPreview`，按模式渲染）③ 底部状态栏（`DocStatusBar`） |
| 主操作 | 无（编辑器是持续保存，无提交动作） |
| 空状态 | 未选中任何条目时：`EmptyDocPanel`「从左侧选一篇笔记，或新建一篇」 |
| 保存与同步状态 | 状态栏常驻：`x MB / 2 MB`、软上限提示、硬上限阻止提示、已同步/待上传/上传失败/冲突 |
| 模式 | 默认**分屏**（左编辑右预览）；仅编辑 / 仅预览；**即时渲染 M1 不做**（细则后续定） |
| 预览同步滚动 | **M1 不做**（属 M04-03 细则），M1 的预览需手动滚动 |
| 快捷键 | `Ctrl/Cmd+S` 无需（自动保存）；`Esc` 关浮层；编辑器内 `Ctrl/Cmd+B/I` 等由 CodeMirror 默认键位提供 |
| 分包 | **编辑器与 Markdown 渲染走动态 `import()`**，不进首屏预算（架构 §14.1） |

## 六、设置壳（M1 最小入口）

| 项 | 内容 |
|---|---|
| 块 | ① 左列分类导航（184px，独立滚动）② 右侧内容区（独立滚动）③ 页头（`PaneHead`：分类名 + 一行简述） |
| 分类（M1 只放 3 个） | **通用**（默认落地：主题三档 浅色/深色/跟随系统，默认浅色）· **账户与安全**（修改登录密码、退出登录）· **实例管理**（**仅 owner 可见**：注册开关 + 到期自动关闭） |
| 主操作 | 各页最多一个：通用页无（即时生效）；账户与安全页「修改登录密码」；实例管理页「保存」 |
| 空状态 | 不适用 |
| 说明 | 其余 7 个分类（编辑器/隐私锁/版本与回收站/备份/分享/MCP/数据管理）**M1 不进导航**，避免空入口；M2 补内容后再加 |
| 主题 | 切换**只改主题属性、不整页重渲染**（DESIGN.md §3.2-3）；跟随系统时响应系统变化，无 `matchMedia` 环境回退浅色 |

## 七、跨屏状态

| 状态 | 表现 |
|---|---|
| 未登录 / 会话过期 | 任意路由 → 登录页；**本地未上传改动保留**，重新登录后继续上传 |
| 离线 | 顶栏同步胶囊显示「离线，改动会在联网后上传」；可正常编辑（本地优先）；登录与注册在离线时直接提示需要联网 |
| 上传失败 | 列表行显示「上传失败」小标记；M1 只提示，**失败列表界面属 M2** |
| 冲突 | 顶栏/列表提示「已在其他设备更新」；副本条目出现在列表里（标题含「冲突副本」）；「对比两者 / 保留某一份」界面属 M2 |
| 加载中 | 列表首次加载用骨架行（`Placeholder`），禁止静默等待 |

## 八、M1 界面明确不做（避免范围蔓延）

- 快速录入框、Memo 时间轴/瀑布流、待办列表/看板、首页卡片组（M2）
- 搜索界面（顶栏搜索框 M1 仅占位）、标签视图、最近编辑/收藏视图（M2）
- 笔记本树与文件夹管理界面（M2；M1 只有根目录）
- 侧滑详情（DESIGN.md：能力保留但不由条目列表触发）
- 表格编辑器、附件与图片、版本历史、回收站界面（M4）
- 加密空间的任何行为与占位（M3；M1 导航里**不出现**加密空间项）
- MCP、数据管理、备份/分享设置页（M5/M6）
- 移动端/窄屏布局（后续定；只守 §2.4 的兼容底线）
