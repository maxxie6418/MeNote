## 0. 先说一条已经自己判掉的（第 10 条）

**首页统计是否计入加密条目** —— 原以为需要你拍板，核过以后**不需要**：

- 《隐私锁设计》v1.3【已定·用户确认 2026-09-27】在三处写明"**统计计数一律计入**全部内容（含标签云数字），**不因锁定 / 解锁改变**"，并明确"实现上'算统计'的函数**根本不接受解锁态入参**，避免以后有人顺手加过滤"；
- 代码现状**正是如此**：`homeStats(items)` 与 `topTags(items)` 都不接受 `gate`，条数与标签云数字都把加密条目算在内；而 `recentPreview` / `openTaskPreview`（**列表**，不是计数）接受 `gate` 并过滤 ✓ 与定稿的"列表受门禁、计数不受"分工一致。
- 冲突只剩在**未提交的首页稿文字**里（那条"锁定时不计入（6.9）"的旧口径）。**结论：以实现与已确认定稿为准——计入**；首页稿与 `wiki/设计文档` §6.9 的那句话等 M4 收口时随 v7.6 一并改（若你选"先不动设计文档"，则至少把首页稿里那句旧口径标作废）。
