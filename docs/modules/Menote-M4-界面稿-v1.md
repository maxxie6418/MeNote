## 二、表格视图 `TablePanel`（含图册与损坏降级）

**落点**：`features/tables/`。**排布方式【沿用】**：表格是**主操作区独立页**（`DESIGN.md` §2.6），不用左列、右列占满；顶栏与功能栏不变。

### 2.1 有哪些块（自上而下）

| # | 块 | 组件 | 内容 |
|---|---|---|---|
| 1 | 正文头 | `DocHead` | 标题（可直接编辑，17px）+ 单篇加密时的锁标识（`.enc-mark`，沿用 M3 §六）+ 右侧「更多」菜单（`DocMoreMenu`：加密此表格 / 移动到… / **版本历史** / 存为版本 / 分享 / 收藏 / **降级为普通笔记** / 删除） |
| 2 | 表格工具栏 | `TableToolbar`【本稿决定，需登记】 | 左：「表格 / 图册」**盒式分段控件**（`SegmentedControl`，原型 `#tableMode`）；右：「新增行」次操作按钮（`Button.sm`）、「筛选与排序」弱操作按钮（`IconButton` + `aria-label`，激活时按钮带选中态并在其下展开 `TableFilterBar`） |
| 3 | 表格区 | `TableView` | `_id` 首列 + 数据列；表头固定（**不参与滚动**），表体滚动；列多时**容器内横向滚动**（不整页横向滚动） |
| 4 | 图册区（另一档） | `GalleryView` | 自适应网格卡片（原型 `minmax(148px,1fr)`）；卡片 = 图片列缩略图（或 `CoverPlaceholder`）+ 标题 + 属性胶囊 |
| 5 | 筛选排序条 | `TableFilterBar`【需登记】 | 按列筛选 + 按列排序的控件条；**纯本地**，关闭即重置（设计 §2.4） |
| 6 | 大小与上限提示 | `SizeTag` + `WarnBox` | 常驻显示大小（与笔记同一处状态栏）；软上限变色、硬上限阻止保存 |
| 7 | 底部状态栏 | `DocStatusBar` | 左：同步状态（`SyncTag`）；右：`N 行 · M 列` + `SizeTag`（如 `742 B / 1.9 MB`）。**加密状态条与尺寸提示条已并入此栏**，不各占一条 |

### 2.2 表头与行首 `_id`

- **表头**：列名 + **列类型图标**（`Icon`，走 sprite：`note`/`hash`-类无、按 §9.1 现有分组选最近的 symbol；**图标不可单独表意**，`title` 与 `aria-label` 给「列类型：文字」这类文字）+ **排序指示**（当前排序列显示 `chev-d`/`chev-up` 之一，其余列不显示）。
- **列头菜单**【本稿决定】：点列名右侧的 `IconButton`（`more`）打开 `DropdownMenu`，仅放**三个入口**：「列设置…（打开列定义面板）」「按此列筛选」「按此列排序」。菜单项**不直接增删列**——增删改列一律走 §三 的面板，避免两处维护同一件事。
- **`_id` 列**【沿用设计 §2.2】：6–8 位 base36，**默认隐藏**，可在列定义面板里打开显示；列头菜单对 `_id` 列**禁用**「删除 / 重命名 / 改类型」三项并写明原因（"`_id` 是稳定行 ID，不可修改"）。表头菜单里它也照常提供「按此列排序」。

### 2.3 单元格编辑（点格进入对应控件）

| 列类型 | 点格后 |
|---|---|
| 文字 `text` | 就地变受控输入（单行，不可换行；需要换行写 `<br>`）；`Esc` 取消、`Enter` 提交、失焦提交 |
| 数字 `number` | 就地数字输入；非数字输入就地报错（`Field` 的错误态），不写库 |
| 单选 `select` | 就地弹 `DropdownMenu`（锚定该格，不足时**自动上翻**，`DESIGN.md` §6.4-1）选一项 |
| 多选 `multi_select` | 同一菜单内**复选框**（`Checkbox`）多选，**选完不收起**，点外部或按 `Esc` 结束 |
| 复选 `checkbox` | 直接切换 `Checkbox`（单击即改，无需进入编辑态） |
| 状态 `status` | 就地弹状态列表，选项以 `Chip`（`tone` 按状态映射）呈现，选中态用 `--primary-soft` 底 |
| 链接 `url` | 就地输入地址；显示为 `.link`（`--primary-ink` + 下划线，`DESIGN.md` §5.3 v1.4）；点链接是**新标签页打开**，编辑用格内的编辑图标按钮 |
| 图片 `image` | 显示 `ImageCell`（缩略图，走 `.t` 缩略图键）；点格打开附件选择（§八）；找不到附件时**显示文件名**并置灰 |
| 日期 `date` | 就地弹日历浮层（`DropdownMenu` 的 `blocks` 整块内容），`blocks` 机制 M2 已做 |
| 标签 `tags` | 就地编辑：已有标签为 `Chip`，输入处可新增；标签与 `TagChip` 同一套外观 |

- **读宽容、写规范**【沿用设计 §2.3】：类型不匹配按新类型宽容解析；解析不了就**显示原文 + 一处灰提示**（格内右上角小 `ⓘ`，`InfoHint` 承载解释），**不改数据**。
- **键盘可达**【沿用 `DESIGN.md` §6.2】：格可用 `Tab` / 方向键移动，`Enter` 进编辑；格是 `button` 语义或 `role="gridcell"` + 键盘事件，不许只靠鼠标。
- **触屏**：单元格视觉尺寸不变，命中区用内边距补足到 ≥44×44px；**不把悬停当唯一入口**（列的插入/删除/改类型都能从列头菜单进入）。

### 2.4 行操作

- **插入行**：工具栏「新增行」（主推进入口）+ 行尾悬浮的 `+`（`IconButton`，触屏等价入口是行首菜单的「在下方插入」）。
- **删除行**：行首 `IconButton`（`more`）→ `DropdownMenu`：「在上方插入 / 在下方插入 / **删除此行**」。
- **拖动排序**：行首的拖动柄（`IconButton`，`Icon` 用现有 `list` 或新增 `grip` symbol）；**触屏与键盘等价入口**：行首菜单里的「上移一行 / 下移一行」，以及拖动柄上 `Alt+↑` / `Alt+↓`。
- **拖动与列排序的冲突**【本稿决定】：列头排序激活时**拖动仍可用**；拖动落位即把该行写回「手动顺序」，并在一次轻提示里说明"已按手动顺序排列，列排序指示已清除"，同时清掉表头排序指示。**不静默丢弃**其中之一。
- **新增行后**：标题列自动聚焦（不是第一列 `_id`），保证「加一行就能打字」。

### 2.5 表格 / 图册切换

- 控件【沿用 `DESIGN.md` §5.3】：「互斥的视图切换」→ **盒式分段控件**（`SegmentedControl`，外框 + `--panel-3` 灰实底选中），**不得**用下划线页签（下划线页签归顶部同级导航）。
- **无图片列时置灰**【沿用功能拆解 M05-08】：图册档按钮 `disabled`（降不透明度 + 禁止指针），**且必须说明为何禁用**——按钮 `title` 与旁侧一行可见文字同时给"添加图片列后可使用图册"（禁用说明不可只置灰，`DESIGN.md` §6.1）；**另给出口**：说明文字里带「添加图片列」的 `.link`，直接打开列定义面板。
- 切换是**纯视图**：不改数据、不改 YAML 的 `views.default`（本稿不改写数据，`views.default` 的写入时机属设计稿；界面只记当前档位于界面状态）。

### 2.6 图册网格与行详情

- 卡片：缩略图（`ImageCell` 的缩略图；无缩略图或解码失败 → 文件图标 + `CoverPlaceholder` 条纹底）+ 标题 + 最多 2 个属性胶囊（`Chip`）。
- **点卡片 → 侧滑出整行属性**【沿用 `DESIGN.md` §6.7】：用**既有** `Drawer`（`app/ui/`，390px / ≤1080px 时 330px，动效 260ms），**在侧栏里可编辑**（设计 §2.4）。这是 `DESIGN.md` §6.7 明确留给图册的场景，**不是**把侧滑详情接回条目列表点击。
- 侧栏块：行属性表单（`Field` 逐项；各类型用 2.3 的同一套控件）+ 底部「关闭」；`Esc` 关闭并把焦点归还卡片。
- **空状态**：无图片列 → 见 2.5（按钮置灰 + 出口）；有图片列但一张缩略图都没有 → 图册区给空状态（"这张表还没有图片"，出口是「切回表格视图」或「在图片列里加一张」）。

### 2.7 按列筛选与排序条 `TableFilterBar`

- 形态【本稿决定】：工具栏按钮下方就地展开的一条**面板内信息条**（不是弹窗、不是菜单），条内是若干「列 + 条件 + 值」行；每行用 `DropdownMenu` 选列与条件，值用 `Field` 输入；右侧「清除全部」次操作。
- **纯本地**：不发请求（设计 §2.4）。
- **关闭即重置**【沿用设计 §2.4】：点「筛选与排序」收起该条 → 筛排状态清零，表头排序指示一并清除；**不落 YAML**。
- 生效时工具栏按钮用选中态，并在按钮旁显示**实时计数**（"筛选后 12 / 48 行"，`DESIGN.md` §5.4-2 要求实时计数必须可见）。
- 未选中任何条件时「清除全部」禁用并说明原因（"还没有筛选条件"）。

### 2.8 大小提示与软/硬上限

| 状态 | 表现 |
|---|---|
| 正常 | 状态栏 `SizeTag` 走 `--muted`：`742 B / 1.9 MB` |
| **软上限 1MB** | `SizeTag` 走 `--amber`（`.soft` 变体）+ 一行**可见**提示"已超过 1 MB，仍可保存，建议拆分表格"；**仍可保存** |
| **硬上限 1,900,000 字节** | 保存被阻止；正文区上方出现 `WarnBox`（危险态）写明"已达 1.9 MB 硬上限，本次改动未保存" + 出口「拆分表格」/「复制本行内容」；状态栏 `SizeTag` 走 `--red`（`.hard` 变体） |
| 单元格 >2000 字符 | 格内就地灰提示"长文本建议写成笔记并在单元格中链接"；**提示但不拒绝** |
| 列数 >50 | 工具栏下方一行可见提示"列数已超过 50，表格会更难读"；**提示但不拒绝** |

> 说明性文字（口径、背景）进 `InfoHint`；**上限提示与实时计数必须可见**，不进 `InfoHint`（`DESIGN.md` §5.4-2 / 禁止项 #8）。

**表格的空状态**【沿用 `DESIGN.md` §5.4-3】：一行数据都没有时，表体区给 `EmptyState`——标题"这张表还没有内容"，说明"列结构已经建好，加第一行就能开始记"，出口是主按钮「新增行」（与工具栏同一动作，不新增第二个主操作：空态出现时工具栏的「新增行」让位给空态按钮，**同屏只有一个实心主色按钮**）。

### 2.9 大表渲染与性能表现

- 表体**虚拟滚动**（设计 §2.5）；表头固定。
- **滚动归属**：表格区**一个**滚动容器（横向滚动也发生在同一个容器内，不嵌套第二层），沿用 `DESIGN.md` §2.7。
- 列宽：内容自适应 + `min-width`，不写死 px；行高按 4px 刻度（`--sp-*`）。

### 2.10 损坏降级

**触发**：解析失败 / 结构损坏。

| 情形 | 表现 |
|---|---|
| 自动降级 | **不静默改数据**：以普通笔记打开，正文区顶部一条 `WarnBox`（危险态）写明"表格结构无法解析，已按普通笔记打开；原文未改动" + 「查看原文」（进原文视图）+ 「下载当前内容」；**降级前先封存一个版本**（`reason = 'pre_convert'`）在后台完成，轻提示只说"已自动封存一个版本（表格降级前）" |
| 主动降级（更多菜单「降级为普通笔记」） | **必须确认**：`ConfirmDialog` 写明 ①影响对象（本表格的结构与列定义将被移除，内容按纯 Markdown 打开）②可恢复性（降级前会先自动封存一个版本，可在版本历史里找回原文）③恢复路径（**不提供反向转回表格**，设计 §2.5）；不确定时用信息措辞写进确认框正文，**不承诺可转回** |
| 降级后 | 条目类型变普通笔记；列表行图标随之变化；「表格 / 图册」与列头菜单不再出现 |

### 2.11 隐私门禁态（加密表格）

- 该篇**已加密且未解密** → 走 `LockedDocPanel`（标题明文可读 + 「输入隐私密码解锁」按钮）；**整个表格区不渲染**（连表头、工具栏、图册档位都不出）。
- 未解密时的其它入口：**版本历史入口整体不可用**（见 §四 4.6）；附件占位（见 §八）。
- 文案红线【沿用隐私锁设计 §9.3】：不写"已加密存储""数据已加密"；锁定态如实说明"不渲染、不进搜索，存储方式不变"。
- 已解密时：标题旁锁胶囊 + 状态栏一条"加密表格 · 已解密 · 4:32 后自动锁定" + 右侧「立即锁定」（沿用 M3 §六 第 3 条）。

## 三、列定义面板 `TableColumnManager`

**落点**：`features/tables/ui/`（`components.md` §十二 已登记 `TableColumnManager`【预留】）。**两处入口**【沿用功能拆解 M05-01/M05-02】：新建表格时自动打开；表头菜单「列设置…」随时打开。

- **容器【沿用 `DESIGN.md` §5.3】**：需要输入与明确阅读后果 → **弹窗**（`Modal` / `Overlay`）。新建表格时**不可点遮罩关闭**（`DESIGN.md` §6.4-5 的例外要显式写：新建流程只能「确定」或「取消」，`Esc` 等于取消）；后续从表头菜单打开时可点遮罩关闭。

### 3.1 块

| # | 块 | 内容 |
|---|---|---|
| 1 | 标题 | 新建时「定义列结构」；编辑时「列设置」 |
| 2 | 说明 | 一行 `InfoHint`（ⓘ）："列定义存在表格正文的 YAML 里；改类型不改动已有文本" |
| 3 | 列清单 | 每列一行：拖动柄 + 列名（`Field` 输入）+ 类型（见第 4 块）+ 行内 `IconButton`（左移 / 右移 / 删除） |
| 4 | 类型选择 | **单选组**（`RadioSet` + `RadioOption`，带标题 + 一行说明）——`DESIGN.md` §5.3：「互斥的**配置选项**（需要解释文字）」→ 单选组，**不用分段控件**。10 个选项：文字 / 纯数字 / 单选 / 多选 / 复选 / 状态 / 超链接 / 图片附件 / 时间 / 标签；每个选项带一行说明（如"图片附件：单元格只写文件名，图片放在正文的「## 附件」章节"） |
| 5 | `_id` 行 | 固定一行（不可删改）：`_id` · "稳定行 ID（6–8 位）" + 「显示此列」**开关**（`Toggle`，默认关）；删除 / 改类型入口**不出现**（不是置灰，是不给） |
| 6 | 底部 | 主按钮「确定」（新建时「创建表格」）；次按钮「取消」 |

- **默认列**【沿用功能拆解 M05-01】：新建时已有**一列「名称（文字）」**；「确定」可直接点，稍后再加列。
- **增列**：清单底部「添加一列」次操作按钮；新列默认名「列 2 / 列 3 …」、类型默认「文字」，插入位置在当前末列右侧；**新增后焦点落在新的列名输入框**。
- **改类型**：单选组即时改；**不改动已有单元格文本**，按新类型宽容解析，解析不了的格显示原文 + 灰提示（同 §2.3）。
- **重命名**：就地输入；列名**允许重复**（用列 ID 定位，不用名字），但重名时给一行灰提示"已有同名列，建议区分"。
- **左右插入 / 调序**：行内左右箭头按钮（键盘可达、触屏可命中）**和**拖动柄两种方式并存；拖动柄是可选路径，**不是唯一入口**。
- **删除列**：`ConfirmDialog`，正文写"此列在所有行里的数据将被移除"；**可恢复性一行写"可在版本历史中找回"**（功能拆解 M05-02 的原话）。

### 3.2 主操作 / 空状态 / 边界

- **主操作**：新建时「创建表格」，编辑时「确定」——**一屏只有一个实心主色按钮**（`DESIGN.md` §5.1）。
- **空状态**：清空到没有数据列时（只剩 `_id`）——清单区给空状态"至少需要一列数据列"，出口是「添加一列」；此时「确定」禁用并写明原因。**不允许 0 列**（正文表格至少要有一列）。
- **边界与降级**：
  - 打开面板期间正文被别的标签页改了 → 提交时冲突处理走既有冲突条（M2 已有），不在本面板里另造提示。
  - 改类型后**失败格计数**给一处**可见**汇总（"3 个单元格无法按新类型解析，已保留原文"），逐格灰提示负责定位。
  - 面板内所有说明文字进 `InfoHint`；**"解析失败""将移除数据"这类后果必须可见**。

## 四、版本历史 `VersionHistoryPanel`

**落点**：`features/versions/`（`components.md` §十二 已登记 `VersionHistoryPanel` / `VersionDiff`【预留】）。**入口两处**【沿用功能拆解 M11-02 / M04-08】：编辑器正文头「更多」菜单的「版本历史」；以及「设置 › 版本与回收站」不进入本面板（那里只有策略设置与回收站入口）。

### 4.1 块

| # | 块 | 内容 |
|---|---|---|
| 1 | 页头 | `PaneHead`：`h1`「版本历史」+ `sub` 写当前条目标题（明文）+ 右侧次操作「关闭 / 返回」（回到打开前的视图） |
| 2 | 版本列表 | 每行：**时间**（`--mono`）+ **中文原因**（`Chip`，见 4.3）+ **大小**（`SizeTag`）+ **备注**（`label`，可空）+ **保留标记**（`keep = 1` 时一枚 `Chip` "保留"）+ 行尾 `IconButton`（`more`） |
| 3 | 行菜单 | 「查看全文」「与当前稿对比」「与另一个版本对比」「恢复此版本」「标记为保留 / 取消保留」（可否取消见 §十-3） |
| 4 | 对比区 | 选一个版本 → 只读全文；选两个（或用「与当前稿对比」）→ **简易 diff**（行级增删，`VersionDiff`；增/删用 `--green` / `--red` **并配 +/- 前缀文字**，颜色不单独表意） |
| 5 | 底部 | 主按钮「存为版本」（§4.4）；次按钮「关闭」 |

- **容器**【本稿决定，见 §十-1】：版本历史是**主操作区独立面板页**（`DESIGN.md` §2.6「主操作区独立页」），不用左列、右列占满——理由是 `DESIGN.md` §2.2 的**弹窗最大宽 400px 装不下并排 diff**，而"需要输入（备注）与阅读后果"用弹窗虽合规、宽度不合规。**不**为此给 `DESIGN.md` §2.2 加"宽弹窗"档（那属改视觉源）。
- **列表滚动**：列表自身一个滚动容器；对比区一个，**不嵌套**（`DESIGN.md` §2.7）。
- 未选中任何版本时，对比区显示 `EmptyState`："选一个版本看全文，选两个（或与当前稿）看差异"。

### 4.2 主操作

- **面板主操作**：`存为版本`（唯一实心主色按钮，落在底部）。
- **行级操作**：查看 / 对比 / 恢复 / 标记保留都是次操作或弱操作，**不得**与主操作并列成第二个实心按钮。

### 4.3 原因的中文映射

【沿用设计 §4.1】`reason` 在界面上显示**中文**，映射表集中在 `packages/shared`：

| `reason` | 界面文案 |
|---|---|
| `autosave_idle` | 停止编辑后自动保存 |
| `session` | 新会话首次编辑 |
| `manual` | 手动保存 |
| `pre_restore` | 恢复前 |
| `pre_conflict` | 冲突前 |
| `pre_mcp` | AI 修改前 |
| `pre_convert` | 表格降级前 |

> 该映射表**需在 `packages/shared` 登记**（本稿不给实现，只定文案）；未来新增 `reason` 时**必须**同步这一处，界面不允许回落到英文原值。

### 4.4 「存为版本」与备注

- 点「存为版本」→ 弹窗内展开一个 `Field`（备注，可空，单选一行说明进 `InfoHint`）+ 「保存」。
- 保存后：列表顶部插入一行（`reason = manual` + 保留标记**默认已打**，设计 §4.1）；轻提示"已存为版本（默认永久保留）"。
- **加密文章的备注**：界面**允许填写**，随正文一起受门禁保护（功能拆解 M11-02 的【补全】按此）。

### 4.5 「恢复此版本」确认框

`ConfirmDialog`，三段必须写全（`DESIGN.md` §6.5：①影响对象与数量 ②是否可恢复 ③恢复路径）：

1. **影响对象**：以「<时间> · <中文原因>」这一版的内容覆盖当前稿；
2. **当前稿会先自动封存**（`reason = 恢复前`，并标记为保留）——**这句必须在确认框里可见**，不能只写"确定要恢复吗"；
3. **可恢复性**：版本表不动，历史不可变；恢复本身可再撤回（用刚封存的那一版再恢复一次即可，设计 §4.4）；
4. 详情里说明"恢复后当前稿的改动不会被丢弃，它已变成一个版本"。

- 确认后：正文区与状态栏按普通保存路径更新；轻提示用**成功态**（不是警告态）。
- **前置**：当前稿尚未保存的改动先走一次普通保存（避免"恢复把未保存内容吃掉"）。

### 4.6 「标记为保留」

- 入口：版本行菜单（功能拆解 M11-05 的入口按此定稿）。
- 标记后：行内出现 `Chip` "保留"，并在列表页脚给一行**可见**说明"已保留的版本不参与稀疏化"（实时计数型信息：显示"已保留 N 个"）。
- 取消保留：菜单项文字变「取消保留」（**保留是双向的**，避免只能加不能减）。

### 4.7 空状态

【沿用 `DESIGN.md` §5.4-3：为什么空 + 下一步做什么】

- 一条版本都没有：`EmptyState` —— 标题"还没有版本"，说明"停止编辑 10 分钟后、或切换标签页时会自动封存；也可以现在手动存一个"，出口是主按钮「存为版本」。

### 4.8 边界与降级

- **加密文章未解密**：**版本入口整体不可用**（设计 §4.5）——编辑器更多菜单里的「版本历史」与「存为版本」**置灰并写明原因**（"需要先输入隐私密码解锁此篇"），不做"列表可见、内容打码"的中间态；`LockedDocPanel` 里也不给版本入口。
- **加密空间内文章**：空间锁定 → 该条目根本打不开（走 `VaultLockedPanel`），不存在"打开后版本入口不可用"的情形；空间解锁期间版本照常可用。
- **手动版本不参与稀疏化**：列表里始终显示；条数上限被策略裁掉的**只有非保留版本**，被裁掉时无提示（设计 §4.3），但列表页脚一行 `InfoHint` 说明保留规则。
- **超长正文**：全文视图自身滚动，不做分页。
- **离线**：版本列表与全文来自本地缓存，可看；「恢复此版本」离线时**置灰并说明**"需要联网"（回滚要写与同步，属写路径）。

### 6.4 空状态

- 标题"回收站是空的"；
- 说明"删除的笔记、表格、Memo 和文件夹会在这里保留 30 天（可在设置里改）"；
- 出口：次操作「返回设置」+ 一行 `.link`「去笔记本」/「回家首页」。**不给**"清空"这类无意义按钮。

### 6.5 隐私门禁态

- **加密空间内条目（或其文件夹）在回收站里**：隐私锁**锁定时标题占位**——显示"加密空间内条目"占位文字 + 锁图标，**不显示真实标题**；**类型与删除时间照常显示**（它们是元数据，不泄露内容）。
- 隐私锁**解锁期间**：显示真实标题，并带"加密空间"标注（沿用 `ItemRow` 的口径）。
- **单篇加密条目**已在回收站里的情形：按 `ItemRow` 既有规则显示**明文标题 + 锁图标 + "已加密"**（标题任何状态可读，隐私锁设计 §9.2-③）。
- 占位行的操作照常可用（恢复 / 永久删除），**不需要解密**（回收站是设置子页面，沿用"元数据操作锁定时可执行"的口径）。
- 文案红线：不写"已加密存储"。

### 6.6 删除入口（M4 补出来的四处）

【设计 §5.1：M2 把删除整体推到 M4，M4 必须补删除入口】

| # | 入口 | 表现 |
|---|---|---|
| 1 | **笔记 / 表格**：正文头「更多」菜单 →「删除」 | 危险操作样式（危险色文字 + 危险色描边，`DESIGN.md` §5.1）→ `ConfirmDialog`：写明"将移入回收站，保留 30 天，可在回收站恢复"；被分享的条目补一句"相关分享会立即失效"（接口位在 M5，M4 文案照写、行为留注释） |

| 3 | **文件夹**：功能栏文件夹行「更多」菜单 →「删除」 | `ConfirmDialog` 必须写清数量（`DESIGN.md` §5.4-5）："文件夹及其中 **N 条内容**、**M 个子文件夹**将移入回收站"——N / M 是**实时计算的计数**，不是固定文案；并说明原路径会保留、恢复时原文件夹不在则回到根目录 |
| 4 | **编辑器内**：无独立入口（收在更多菜单里，保持正文头"只有模式切换 + 更多菜单"的不变量，`components.md` §7.2） | — |

## 七、附件与图片的界面形态（不新增屏）

本节的形态**都落在已有界面里**（编辑器正文、表格图片列、图册卡片），**不新增屏**；附件管理页见第八节。

### 7.1 上传入口与本地预览

| 场景 | 表现 |
|---|---|
| 粘贴 | 编辑器正文内 `Ctrl/Cmd+V` 粘贴图片 → 立即插入占位并开始上传 |
| 拖入 | 编辑器正文区、表格图片列、图册卡片支持拖入；拖入时**可见的落点提示**（虚线描边，`--primary-line`）而不是只改光标 |
| 选择文件 | 正文工具栏 / 表格图片列的「添加附件」按钮（`Button.sm` + `IconButton`） |
| 未上传完成 | 一律用**本地 `blob:` 预览**（设计 §3.2-6；仅本机内存，锁定或离开即撤销），图片显示本地图，非图片显示文件名 + 文件图标 |
| 超过 20MB | 就地可见提示"文件超过 20 MB，请压缩或拆分后上传"（功能拆解 M10-01），**不进入上传** |

### 7.2 上传中与失败重试（outbox）

- **实时计数必须可见**：上传中显示进度（`N%` 或"上传中 2 / 3"），落在**正文底部状态栏**的既有位置（`DocStatusBar` 是"保存与同步状态、大小"的载体，`DESIGN.md` §6.6）——**不新增第二条状态栏**。
- **失败**：状态栏走 `--amber`（失败/待上传同属警告语义）+ 文字"1 个附件上传失败"；**并给可见的重试入口**（状态栏上的「重试」次操作，或点开一个失败清单条）。
- 弱网：进 outbox 重试（设计 §3.2-6）；离线时提示"离线，联网后自动上传"。
- **同一用户重复上传同一文件**：命中去重 → 秒传（不发第二次请求），轻提示"已复用同一文件"；界面**不暴露哈希**。
- 上传中离开页面：不阻塞导航；回来时从状态栏/清单条上能看到未完成项。

### 7.3 缩略图缺失与解码失败

- 图片**未生成缩略图**或解码失败（如 HEIC）→ 卡片与单元格里**以文件图标代替**（`Icon` + `CoverPlaceholder` 条纹底），**原图照常保存**、点击仍可打开原图（功能拆解 M10-01）。
- 缩略图**在浏览器端生成**（设计 §3.3），因此进度语义是"上传中"而不是"服务端处理中"；界面**不出现**"正在生成缩略图"这类服务端加工文案。
- 缩略图加载失败但原图在 → 显示文件图标 + `title`"缩略图不可用，点击查看原图"。

### 7.4 正文里的非图片附件

- 显示为**可下载的文件链接**（功能拆解 M10-01 的【补全】）：`Icon(i-download)` + 文件名，走 `DESIGN.md` §5.3 v1.4 的**链接 `.link`**（`--primary-ink` + 下划线）。**不得**用按钮冒充链接，也不得让链接沿用正文色。
- 显示补充信息：文件大小（`SizeTag` 或行内文字）。**不显示哈希**。
- 找不到附件（引用在、对象不在）→ 显示文件名 + 灰提示"附件不可用"，点它不下载、不报原生弹窗。

### 7.5 隐私门禁下的附件

- 单篇加密且未解密 / 加密空间锁定：**附件占位、不渲染、不进搜索结果**（设计 §3.4 + 隐私锁设计 §9.2）。占位形态**复用** `LockedPlaceholder`（已收敛为一个组件，`components.md` §14.2 第 6 条），文案作 props 传入。
- 文案如实：附件与正文一样**按明文存储**、门禁在界面层生效；**禁止**"附件已加密"。

### 7.6 删除附件引用的入口与取舍【待确认】

三个候选位置，各有代价：

| 候选 | 优点 | 代价 |
|---|---|---|
| A. 附件条目自身旁的 `IconButton`（`trash`） | 直观、就近 | 与"点击下载"、图片的"点击放大"抢同一块命中区，**易误触** |
| B. 图片/文件块的**选中态**才出现的浮动工具条（选中后显示「删除引用」） | 不打扰、命中区可做够大 | 发现性差；**不能**只靠悬停出现（`DESIGN.md` §2.4-2 禁止悬停为唯一入口），必须支持点击选中 |
| C. 收进「更多」菜单（正文头，选中附件时出现「移除附件引用」） | 与现有"操作收进更多菜单"的不变量一致 | 与附件本体距离远，需先选中 |

**本稿默认取 C 为主 + B 为辅**（选中附件后在附件旁给一个**常驻**（非悬停）的小工具条，工具条里的「移除引用」与更多菜单里的同一项是同一个动作）。**待确认**见 §十-5。

- 语义必须写清：**移除引用**≠删除文件。确认框（若需要）写"只从这篇的附件章节移除引用；文件本身在没有别处引用满 30 天后才会被清理"（设计 §3.5）。
- **不建议**在 M4 提供"删除附件文件"的入口——它属附件管理页（M6）。

### 7.7 与既有组件的复用

- 附件在正文里的形态**不新造**块级组件以外的结构：图片走 `ImageCell` / `CoverPlaceholder`，文件走 `.link` + `Icon`，进度与失败走状态栏与面板提示（`WarnBox`）。新增的只有**上传编排**（§九 登记）。

2. **说明与可见的分界**：口径 / 背景 / 用途 → `InfoHint`；警告、破坏性后果、错误校验、实时计数（剩余保留天数、上传进度、筛选后行数、回收站条目数、文件夹删除数量）→ **一律可见**。
3. **空状态必须给出口**：表格空表、图册无图、无版本、回收站为空，四处都写了"为什么空 + 下一步做什么"。
4. **移动端底线**：本稿所有操作都有非悬停、非右键、非拖拽的等价入口（行/列/排序/删除），命中区按 44×44px 补足，滚动每层一个，未发明任何移动端布局。
5. **不承诺做不到的事**：快照文件、分享自动恢复、附件硬配额、降级可转回——四处文案都不承诺。
