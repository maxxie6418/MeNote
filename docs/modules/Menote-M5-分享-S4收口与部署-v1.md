## 一、当前实现与线上部署关系

### 1. 已落地的代码批次

- **S1 服务端（v0.6.13）**：`shares` / `share_items` 迁移 0005；管理侧创建、列表、改密改期、撤销；公开侧状态、解锁、正文、附件；实时失效检查；无状态 HMAC 访问令牌。
- **S2 管理端（v0.6.14）**：笔记「更多 › 分享」入口、创建弹窗、设置 › 分享、公开标记、实例设置里的分享子域、加密 / 移入回收站后的分享行清理。
- **S3 查看器（v0.6.15）**：`/s/<分享ID>` 路径分流；失效页、密码页、只读 Markdown、附件令牌取回与 blob URL、只读表格网格、图册切换。

### 2. 入口实现的已知偏离

架构入口表原定 `apps/web/share.html` 独立入口；实际 `@cloudflare/vite-plugin` v1.60 接管客户端入口，手写第二 html input 会报 `UNRESOLVED_ENTRY`。现按架构同一节已经定下的 Static Assets SPA 规则实现：

- `/s/<分享ID>` 未命中静态文件时回落 `index.html`；
- `apps/web/src/main.tsx` 按 pathname 分流；
- 主应用与查看器均动态导入，分享访客不拉编辑器与同步 chunk；
- 偏离原因、回写目标已写在 `main.tsx` 与《M5 分享设计》v1.3 修改记录中。

这不是第二套页面骨架，也不拆 Worker；分享子域与主域仍指向同一个 Worker/Static Assets 部署。

## 二、Cloudflare 一次性部署动作

以下动作需要实例管理员在 Cloudflare 控制台或 DNS 提供商完成；代码仓库本身不应伪造这些外部状态。

1. 选定分享子域，例如 `share.example.com`。
2. 为该子域配置 DNS 记录，指向当前 Worker 的自定义域 / Workers 路由目标。
3. 配置 Workers Route：`share.example.com/*` → **与主应用相同的 Worker**。不创建第二个 Worker。
4. 在 Menote「设置 › 实例管理 › 分享子域」填入 `https://share.example.com` 并保存。留空时仍可用当前站点的 `/s/<分享ID>` 作为回退。
5. 确认 HTTPS 证书已对分享子域生效；分享查看器依赖 WebCrypto 的密码派生，HTTP 不作为线上验收环境。
6. 确认主应用会话 Cookie 仍不带 `Domain` 属性（当前 `middleware/session.ts` 的既有实现），使主域会话不会发到分享子域。

## 三、线上人工验收清单

**先分清两类，别把能本地验的也堆到线上**：查看器是**路径分流**（`/s/<分享ID>`），同域也能跑；只有**链接形态、跨 origin 会话隔离、HTTPS 证书**这三件事非子域不可。标 🟡 的可在 `pnpm dev` 本地验（本地无子域时链接自动退回同域 `/s/<id>`，见 `features/shares/model.ts:6-8`），标 🔴 的必须上线后点。

| # | 用户动作 | 可观察结果 | 状态 |
|---|---|---|---|
| 1 | 主域登录，打开一篇普通笔记，点「更多 › 分享」 | 弹窗可创建，密码为空时说明无需密码；过期档位可选 | ✅ 已验（本地，2026-10-03，见 §四-2） |
| 2 | 创建带密码、7 天有效期的分享 | 返回完整子域链接，复制按钮成功；正文头出现「公开」 | 未验证 |
| 3 | 无登录态打开 `/s/<分享ID>` | 只加载分享页，不出现主应用导航、编辑器或同步错误 | 未验证 |
| 4 | 访客输错密码 | 明确显示「密码不对」，不泄露其它条目或用户信息 | 未验证 |
| 5 | 访客输入正确密码 | Markdown 正文只读呈现；标题、清单、图片可见 | 未验证 |
| 6 | 打开含图片附件的分享 | 图片能显示；附件请求带令牌但链接本身不把令牌放进 URL | 未验证 |
| 7 | 分享一篇表格且有图片引用 | 默认只读表格；可切到图册；没有筛选/排序控件 | 未验证 |
| 8 | 设置 › 分享复制链接、改密码、改有效期 | 修改成功；旧密码失效；列表状态即时刷新 | 未验证 |
| 9 | 撤销分享后刷新访客页 | 看到「链接已失效」；设置列表不再显示该分享 | 未验证 |
| 10 | 将已分享条目移入回收站或开启单篇加密 | 访客实时失效；主应用提示「相关分享已自动撤销」 | 未验证 |
| 11 | 等待一个已过期链接 | 访客看到失效页；不需要 Cron 才失效 | 未验证 |
| 12 | 在无 R2 桶或附件缺失环境打开普通文本分享 | 正文仍可看；缺失附件不阻断整篇正文 | 未验证 |

### 2. 本地真机点验（2026-10-03，`pnpm dev` + 本地 D1，`admin` 种子账号）

**这一段是本轮新增**：查看器按 `/s/<分享ID>` **路径**分流（架构 Static Assets 的 SPA 回退），所以**访客侧行为不依赖子域**，能在本地跑成证据。已过：

| 观察 | 结果 |
|---|---|
| 笔记「更多 › 分享」入口 | 菜单出现「分享」，与「导出 Markdown」「版本历史」同级；隐私类四项按预期置灰 |
| 创建弹窗 | 「创建分享链接」可开；密码标注「留空 = 无需密码」；有效期五档齐全（永不过期 / 1 天 / 7 天 / 30 天 / 自定义），**7 天为默认选中**；说明性文字收进 `InfoHint`（`DESIGN.md` §5.4-1） |
| 笔记本体 | 标题 + 正文（列表、待办勾选、加粗）在编辑器与列表摘要均正确落库 |

**仍未验（等用户）**：访客侧四态、设置页改密改期、撤销与自动撤销、过期链接——都要么在访客浏览器里看，要么需要子域链接形态。

### 3. 自动化与自动化都替代不了的

- **自动化替代不了**：真实 Cloudflare 子域路由、跨 origin 的会话隔离、浏览器真实 object URL 图片、访客密码流程、表格密集内容视觉、真实 R2 附件请求。
- **本地已能替代的**：上面 §2 列的三项，不必再让用户重复点。
- 自动化用例本身已覆盖的失效四路（撤销 / 过期 / 进回收站 / 被加密）见 `apps/worker/test/shares.test.ts`；S4 要点的是**界面观感与子域形态**，不是这套逻辑。
