## 一、依据与结论

- **需求是既定的**：`wiki/Menote-设计文档-v7.4.md` §7.1 已把「即时渲染」列为四档编辑模式之一（默认仍是双栏），并明确"该模式是**纯展示层**，不改变'整篇 md'的编辑粒度"。
- **技术路线也是既定的**：`wiki/Menote-项目架构-v1.md` §3.3 写明"基于 Lezer 语法树的装饰（`Decoration.replace` / `widget`），**只对视口内的节点计算装饰**，光标所在行显示源码"。
- **本轮结论**：**可行且已落地**。全部所需能力都来自已有的 CodeMirror 6 包，**没有新增任何生产依赖**。
- **一个必须知道的前置事实**：`@codemirror/lang-markdown` 的 `markdown()` **默认 base 是纯 CommonMark**（不含 GFM）——在换 base 之前，编辑器语法树里 `| a | b |` 不是表格、`- [ ]` 不是任务清单、`~~x~~` 不是删除线（`[x]` 甚至被解析成链接）。现在统一改用 `markdown({ base: markdownLanguage })`（`markdownLanguage` = commonmark + GFM + 下标/上标/emoji，由该包自己导出，不引新依赖）。

## 二、首期覆盖表（用户 2026-09-28 拍板：**B 范围，文本级 + 图片占位**）

| 语法元素 | 首期 | 交互 / 呈现 |
|---|---|---|
| ATX 标题 `#`～`######` | ✅ | `#` 与紧跟的空格藏起来；整行按层级上字号（只用现有 6 档刻度：20/17/14/13/12/11） |
| 粗体 / 斜体 / 删除线 | ✅ | 标记（`**` `*` `~~`）藏起来，文字加粗 / 倾斜 / 删除线 |
| 行内代码 | ✅ | 反引号藏起来，内容等宽 + 底色（与预览 `.markdown-body code` 同取值） |
| 链接 `[label](url)` | ✅ | **只留 label**，方括号与地址都藏起来（地址里的 sha256 是内部标识，界面不该出现，M4 界面稿 §7.4） |
| 自动链接 `<url>` / 裸 URL | ✅ | 尖括号藏起来；裸 URL 文字保留（它本身就是要读的内容） |
| 引用 `>` | ✅ | `>` 与紧跟的空格藏起来；整行左侧竖线 + 次一级文字色 |
| 无序列表 | ✅ | 项目符号换成 `•`（widget） |
| 有序列表 | ✅ | **数字保留**（数字本身有信息量） |
| 分隔线 `---` | ✅ | 藏起来，由该行上边框画成一条线 |
| 图片 | ⚠️ 占位块 | 换成虚线占位块，文案只带 alt（上传中的附件 alt 就是「上传中：文件名」）——**不显示地址**。内联图片见 §七-4 |
| 代码块 | ⚠️ 只上底色 | **围栏与语言保持源码可见**，只给行底色；语言高亮见 §七-5 |
| GFM 表格 | ❌ 保持源码 | 见 §七-3（表格就地编辑是另一个子项目级的工作量；表格条目本来就有专门的表格界面） |
| 任务清单 `- [ ]` | ❌ 保持源码 | 见 §七-6（要配真可点的复选框；首期不放假复选框，`DESIGN.md` 禁止"点了没反应"的控件） |
| front matter（Memo/表格的 YAML） | ❌ 不动 | 见 §七-7（笔记正文一般没有；降级表格的笔记会有 `menote:` 块） |
| 标签 `#标签` | ❌ 不动 | 见 §七-8（要做成 chip 需要自己写正则扫描，树里没有对应节点） |

## 三、交互细则

1. **按行显示源码**（架构原文）：光标（或跨行选区）覆盖的**行**不隐藏任何标记；其余行照常渲染。
   - **一处细化**（本轮加的，实现中发现）：**编辑器失焦时整篇渲染**。CM6 的选区在打开文档时默认落在文档开头，若严格按"光标行"执行，刚打开一篇笔记会看到第一行一直露着 `##`——像"没渲染"。现在失焦即整篇渲染，点进哪一行哪一行才回源码。
2. **跨行选区整段露源码**：选中多行时，选区覆盖的行都不隐藏——**复制出来仍是带标记的 md**。
3. **藏掉的标记是原子区间**（`EditorView.atomicRanges`）：方向键、退格一次跨过去，不会"钻"进看不见的 `**` 里。
4. **点击已渲染文本**：由 CM6 自己映射光标位置（占位块 `ignoreEvent() = false`，不吞掉鼠标事件）。
5. **中文输入法**：`view.composing` 期间**不重算装饰**，只把已有装饰按变更映射（`RangeSet.map`）——重算会把组合中的字/候选区替换掉。见 §四-2。
6. **表格条目不显示模式切换**（既有口径）：表格有自己的"表格 / 图册"档位，即时渲染对它没有意义。

## 四、实现约束与性能

1. **只算视口**：Lezer 的树是**懒解析**的（实测：建 `EditorState` 后树只覆盖前 ~3011 字符），所以插件里用 `ensureSyntaxTree(state, 视口末端, 50ms)` 补可见区；超预算就退回部分树——那一屏先显示源码，下一帧再渲染。装饰构建本身很便宜（实测视口 4KB 约 0.4–1.1ms / 397 处）。
2. **输入法安全**（本项目最该守的一条，中文优先）：组合期间跳过重算 + 位置映射；这条**只能靠人工用真实输入法验**，见 §七-1。
3. **重建时机**：`docChanged | viewportChanged | selectionSet | focusChanged` 之一才重算；`docChanged` 时先 `map(changes)` 保住位置（即使后面不重算也不会指向已消失的区间）。
4. **可测性**：核心是**纯函数** `buildLivePreviewDecorations(state, {from, to, activeRange}) → { decorations, atomic }`——只依赖 `EditorState` 与语法树，不需要视图，所以能在 jsdom 里逐条断言（全仓既有的 CM6 测试都只能 mock 掉整个编辑器）。
5. **切换不重建文档**：`live` 走 `Compartment` 重配置（与只读开关同一套），"仅编辑 ↔ 即时渲染"在 React 树里位置相同、不会重新挂载；行号与即时渲染扩展互斥（渲染视图里行号只是噪声）。

## 六、实测（2026-09-28，本地真实 Chrome + 同一套量法）

| 项 | 结果 |
|---|---|
| 首期元素渲染 | 标题 / 粗斜体 / 删除线 / 行内代码 / 链接（只留 label）/ 引用 / 无序与有序列表 / 分隔线 / 图片占位 / 代码块底色 —— 逐项在 `.cm-content` 的可见文本里核对，`**`、`~~`、md 链接地址、sha256 **均不出现** |
| 活动行规则 | 失焦：整篇渲染；点进「引用」行：该行显示 `> 引用一行`，其余行照常渲染；**真实按键**输入后源码标记完好（`**粗体**` 原样保留） |
| 模式切换 | `仅编辑 → 即时渲染` 后 `.cm-content` **仍是同一个 DOM 节点**（未重建文档）；即时渲染下无行号 |
| 设置页 | 第四档 `disabled=false`，说明文字为新的细则摘要 |
| 输入路径成本 | 小文档下打字无长任务；800KB 文档"敲一个字"的增量解析 + 局部装饰 headless 实测中位 26ms（真机待复核，见 §七-2） |

## 七、未做 / 待办（按建议顺序）

1. **中文输入法人工验收**（必做，先于后续任何扩展）：用搜狗/微软拼音在即时渲染下连续输入、翻页选词、删除组合字，确认候选窗位置与文字不丢。自动化测不了。
2. **长文档深滚动复核**：800KB 级文档滚到中后段，确认 `ensureSyntaxTree` 补解析跟得上、无装饰错位。
3. **GFM 表格内联渲染**：明确不在首期。要做需另开设计（表格就地编辑 = 一个小型表格编辑器；还要与表格条目的专门界面统一口径）。
4. **图片内联**：接 `/api/attachments/h/<sha>`，含加载失败/尺寸/懒加载三态，以及 `#pending` 上传中的占位与状态联动。
5. **代码块语言高亮**：要引语言包（体积），并复用预览的配色。
6. **任务清单可勾选**：真复选框 widget → 勾选即改文档（`[ ]` ⇄ `[x]`）。
7. **front matter 处理**：Memo 与降级表格的 YAML 块在即时渲染里怎么呈现（隐藏？折叠成一行提示？），需要拍板。
8. **`#标签` 渲染成 chip**：树里没有对应节点，要自己扫正则。
9. **`DESIGN.md` 补一节**：即时渲染的视觉细则（字号映射、各元素的样式归属）目前只在本文与 `app.css` 注释里；`DESIGN.md` 是唯一视觉源，**改它需要你点头**，本轮没动。
10. **移动端**：窄屏 / 触屏下即时渲染的表现（含软键盘弹起时的视口变化）随移动端布局一并做。

## 八、有意与 Obsidian / Typora 不同的地方

| 点 | 我们的做法 | 理由 |
|---|---|---|
| 表格 | 保持源码 | 表格就地编辑是子项目级工作量；表格条目另有专门界面 |
| 代码块 | 围栏保留 + 底色 | 藏围栏会在块头留一个空行（CM6 折叠整行的写法很啰嗦），收益不抵复杂度 |
| 任务清单 | 保持源码 | 不放假复选框（`DESIGN.md` 禁止"点了没反应的控件"）；真交互留下一步 |
| 图片 | 占位块 | 用户 2026-09-28 拍板的首期范围 |
| 失焦时 | 整篇渲染 | 见 §三-1（否则刚打开笔记像"没渲染"） |
