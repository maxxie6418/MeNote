## 七、怎么用这份清单

- 每条回一个词即可：**做** / **不做** / **以后做**（例如"1-1 做、1-4 以后做、2-1 不做、4-1 以后做"）；
- 标"建议做"的多为**小改动且观感明显**（时间轴两列与节点、`more` 字形、空状态图标块、分组圆点）；
- 标"**需你定**"的多为**会改变屏形态**的（笔记行横竖、待办行/卡、首页重做、那年今日），
  改完用户的肌肉记忆会变，所以我不擅自动。
