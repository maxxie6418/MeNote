## 一、设置页导航

保留现有左列导航 + 右侧内容双滚动结构，不增加子集或第三级层级。左侧只渲染当前已实现的主分类按钮：通用、编辑器、隐私锁、版本与回收站、账户与安全、实例管理（仅 owner）、关于。

视觉采用分组卡片式：分组标题仅为弱化的非交互文本，不能点击；主分类仍是一层按钮，不改变路由和顺序。分组如下：

- 常用：通用、编辑器、隐私锁
- 数据：版本与回收站
- 账户：账户与安全
- 管理：实例管理（仅 owner）
- 关于：关于

左侧导航增加组间留白、组标题与卡片边界，主分类行保留清晰的 hover / selected 状态，避免分类项堆叠成一团。未实现的设置分类继续不进入导航。

## 二、头像状态圈

顶栏不再单独显示隐私锁胶囊；头像账户入口成为隐私状态的唯一可见入口。点击头像仍打开原有账户快捷菜单，菜单内的设置、退出登录、立即锁定、主题等动作不变。

头像状态映射：

| 隐私状态 | 外圈 | 语义 |
|---|---|---|
| 未启用 | 不显示外圈 | 没有隐私锁状态 |
| 已锁定 | 绿色实线圈 | 隐私内容已锁定 |
| 已解锁 + minutes | 橙色动态环 | 环形进度表示剩余时间比例，时间减少时环同步缩短 |
| 已解锁 + session | 橙色虚线圈 | 本次会话解锁 |
| 已解锁 + device | 橙色实线圈 | 当前设备长期解锁 |

状态圈只表达锁定 / 解锁及解锁持续形态，不显示“本次会话”“N 分钟”“本设备始终解锁”等文字。可访问名称和必要说明通过头像按钮的 aria-label / title 提供，不把颜色作为唯一信息。

倒计时环每秒刷新，使用现有 `expiresAt` 与当前时间计算剩余比例；不修改隐私状态机和持久化协议。缺少有效到期时间时，倒计时态退化为橙色实线圈，避免出现空环。

## 三、实现边界

- 不修改数据库、API、同步协议和隐私锁状态机。
- 不新增主题颜色体系，状态圈只使用现有 `--green`、`--amber`、`--primary` 等令牌。
- 不改变账户菜单内容和已有操作。
- 设置页内容卡片与各设置项业务逻辑保持不变，仅调整导航结构与版式。
- 倒计时状态圈使用 CSS/SVG 表现，圆环比例由组件计算。

## 四、验证

- 设置导航测试断言分组标题为非交互元素、主分类仍为单层按钮且 owner 条件正确。
- 头像状态圈测试覆盖未启用、锁定、minutes/session/device 四种已启用状态，并断言倒计时环比例随时间变化。
- CSS 级联测试钉住设置导航分组间距与状态圈的线型 / 令牌。
- 运行相关 Web 测试、类型检查、全仓测试与 lint。
