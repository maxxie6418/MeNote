## 一、分类与导航（**照定稿 11 类**）

| # | 分类 | 本轮进场 | 说明 |
|---|---|---|---|
| 1 | 通用（默认落地页） | ✅ | 启动视图 / 时区 / 主题 / 快捷菜单配置 / 待办筛选条形态；**新增**：笔记本树是否显示条目（见笔记本稿） |
| 2 | 账户与安全 | ✅ | 修改登录密码 / 登出（**补二次确认**）/ 登录设备与会话（占位，等后端） |
| 3 | 编辑器 | ✅ | 默认编辑模式四档（含已落地的即时渲染）；**新增说明**：即时渲染首期覆盖范围（进 `InfoHint`） |
| 4 | 隐私锁 | ✅ 重排为六卡 | 见 §四 |
| 5 | 版本与回收站 | ✅ | 封存间隔 / 保留策略 / 回收站天数 / 回收站入口（现有） |
| 6 | 备份 | ❌ 不进导航 | 等 M5（后端与导出没做） |
| 7 | 分享 | ❌ 不进导航 | 等 M5 |
| 8 | MCP | ❌ 不进导航 | 等 M6 |
| 9 | 数据管理 | ❌ 不进导航 | 等 M6（附件管理页也在里面） |
| 10 | 实例管理（仅 owner） | ✅ | 注册开关（**补"到期自动关闭"**）/ 成员账户管理（占位）/ 实例总用量（占位，等后端）/ 更新通知（占位） |
| 11 | 关于（排最后） | ✅ | 版本号 + 仓库地址（现有，合专稿） |

**三条与定稿一致的口径**：①**没做的分类不进导航**（不是灰掉——灰掉会让人以为点了会有什么）；②导航里「实例管理」带 **owner 徽标**，非 owner 看不到该项；③分类顺序与上表一致，通用第一、关于最后。

**导航形态**：沿用「左列分类导航（`--settings-nav-w` 184px，独立滚动）+ 右列内容（独立滚动）」——这是 `DESIGN.md` §2.2 / §2.7 已定的结构，**不加第三级**；但类名从借用功能栏的 `.nav-item` 改为**语义化的 `.set-nav-item[data-set]`**（`components.md:380` 登记过、含 owner 徽标），选中态沿用"主色浅底 + 主色字"。

## 二、页头与行内控件统一

| 点 | 现状 | 定稿做法 |
|---|---|---|
| 页头 | `.settings__head` + `h2` + `p`（`--fs-small`），与首页 `.pane-head h1`、待办 `.tkhead` 三套 | **统一成一条**：`h1`（`--fs-title` 17px/650）· 说明（**收进 `InfoHint`** 或一行 `--fs-micro` 简述）· 分类计数；出口「← 返回笔记」保持右端。**不抽公共 `PaneHead`**（那属公共组件改动；等第二个屏也要同款时再抽） |
| 互斥选项 | 主题/启动视图/编辑模式/解锁档位用 `.radioset`；**时区是原生 `<select>`** | 除**时区**外全部用 **`.radioset`（单选组：标题 + 说明）**，与 `DESIGN.md` 一条规则一致。**时区是唯一例外**（v0.5.13 定）：完整时区表 400+ 项做成单选组会把这一页撑爆，**保留原生 `<select>`**，只把外层版式统一到 `.setrow__control`；可搜索下拉是另一个组件（§八-3），不在本轮 |
| 开 / 关 | 多数是 `<button role="switch" class="toggle">`；**版本页「不限」是 `label + checkbox`** | 统一 `role="switch"`（把那一处改过来即可，**不新建公共组件**） |
| 行内输入 | 版本页用 `.setrow__control` + `.setrow__unit`；隐私页把 `<input class="field__input">` 直接挂在 `.setrow` 下 | 统一用 `.setrow__control` 包住输入 + `.setrow__unit` 放单位；字段级校验用 `Field` 的 `.hint` / 错误位 |
| 间距 | 有几处内联 `style={{marginTop}}` 与刻度外裸值（`80px`/`2px`/`3px`/`10px`） | 间距一律走父容器 `gap` 与 `--sp-*`；把违规处改成刻度值（`DESIGN.md` §4.3 + 禁止项 #14） |
| 文字链接 | `PrivacySettingsPage` 用 `<button class="link">` 冒充链接 | 用 `.link` 的**文字链接**语义（`DESIGN.md` §5.3）；需要按钮语义的（如「取消」）改成幽灵按钮而不是链接样式 |

## 三、说明文字的分工（一次定死）

| 内容 | 去处 |
|---|---|
| 用途 / 口径 / 背景 / 里程碑说明 | **`InfoHint`（ⓘ）**，不平铺 |
| 字段级一句话解释（如"随时可以在正文区切换"） | `.setrow__desc`，**每条最多一句** |
| **警告、破坏性后果、错误与校验、实时计数**（回收站条目数、保留天数、隐私锁状态） | **必须平铺可见**（禁止项 #8 明确） |

设置页现有 **12 处**平铺说明按上表重排。

## 四、隐私锁页：回到六卡结构（M3 界面稿 §四）

顺序即操作顺序：①**状态**（未启用＝用途 + 主按钮「启用隐私锁」；已启用＝状态文字 + 「**立即锁定**」）→ ②**隐私密码**（修改；忘记 → 重置，**重置前必须明说"旧备份解不开"**，且**二次确认**）→ ③**解锁档位**（三档 + N 分钟 1/5/15/30/60）→ ④**隐私范围**（**「加密空间：始终在范围内」只读行** + Memo 开关（默认开、**同时管 Memo 派生的待办**）+ **预留扩展位一行**）→ ⑤**搜索**（「解锁时可搜索加密内容」开关，只管正文）→ ⑥**关闭隐私锁**（**独立危险区卡片**：有隐私内容时禁用并写明原因；可关闭时**二次确认**）。
**另补**：未启用时只显示 ①；离线时"启用 / 修改 / 重置 / 关闭"四个入口**置灰并说明"需要联网"**（档位、范围、搜索可离线改）。

## 五、破坏性操作统一补确认

`DESIGN.md` §6.3/§6.5 点名必须二次确认的：**登出**、**关闭隐私锁**、**重置隐私密码**（现有三处都是单击即执行）。
做法：复用现有 `Modal` + danger `Button`（**不新建 `ConfirmDialog` 组件**，等第三个非设置页用途再抽）。
文案模板：**做什么 → 影响哪些对象、多少数量 → 能不能恢复、怎么恢复**（禁止项 #7）。

## 六、每类的主操作

| 分类 | 主操作（实心主色，每区域最多 1 个） | 次操作 |
|---|---|---|
| 通用 | 无（全部即时生效） | — |
| 账户与安全 | 「修改密码」（表单提交） | 登出（危险档 + 确认） |
| 编辑器 | 无 | — |
| 隐私锁 | 未启用：「启用隐私锁」；已启用：无（「立即锁定」用次操作） | 修改 / 重置 / 关闭（危险） |
| 版本与回收站 | 无（即时生效） | 「打开回收站」用**次操作**（它是导航，不是本页主操作） |
| 实例管理 | **无主操作**（v0.5.13 定：本表原写「保存」，与 §八-4"维持即时生效、不加保存按钮"冲突，**以 §八-4 为准**） | 切换注册开关、设到期时间（都是即时写入） |
| 关于 | 无（纯信息页，唯一可点是仓库链接） | — |

> 现状里"5 个分类零主操作、隐私锁页同时 1 主 2 次平级、版本页拿次操作承载推进动作"这三处一并按上表收口。

## 八、待拍板（**四条已定 · v0.5.13**）

1. 四个"还没做"的分类（备份/分享/MCP/数据管理）**不进导航** —— **已定**（避免假入口；导航只列已实现的 7 类）。
2. 时区、保留策略、封存间隔、快捷菜单配置、笔记本树显示条目这些**不折叠**（设置页本来就不长；分类已承担分组）—— **已定**。
3. 保留密度（现在只读展示）**要不要开放修改**？开放要先改定稿的五段密度算法 —— **仍挂**（等定稿改口径）。
4. 保存方式**维持"即时生效 + 入队同步"**（只给越界输入就地报错，不加"保存"按钮）—— **已定**（所以实例管理也没有主操作，见 §六）。
5. 移动端：本轮只在稿里声明方向（左列折叠成下拉 / 顶部页签），**不动具体骨架**（`DESIGN.md` §2.4 未定稿）—— **已定**。
