这一屏是怎么组织的

四个块（自上而下）

块高说明
① 顶栏54px暂定只放站名 + 头像（虚框那处是待确认的同步胶囊位置）
② 三档页签44px下划线页签，不是盒式分段控件
③ 快捷输入行 / 输入面板44px / 33%常态一行；点开就地撑开，内容被下推
④ 内容区剩余全部本屏唯一的滚动容器

三个档位的内容

  • 首页 —— 最近编辑 + 收藏两组卡片，每组一个「全部」入口。
  • 笔记 —— 笔记本树（两层：文件夹 / 子文件夹 / 条目），节点带计数与待上传标记。
  • Memo —— 按天分组的时间轴，条目带时间、标签、清单与置顶标记。

录入模式与页签刻意做成两种造型

页签是下划线（导航），录入模式是盒式分段控件（参数）。两个三档上下相邻， 如果做成同一种按钮就分不清「我在哪」和「我要记什么」。这条来自 DESIGN.md §5.3 与 §2.5-4。

主要交互

  1. 点页签切档位：内容换、输入面板自动收起（不改高度、不推挤页签）。
  2. 点输入行展开到 33%（360×740 框下约 240px）；再点一次或发布后收起。
  3. 页签位置固定不动——这是 C 与 A 的关键差别：A 里输入区一收一放，页签会上下跳。
  4. 可点元素命中区不小于 44×44px；不作悬停依赖；viewport 允许缩放。

空状态

如「还没有收藏的笔记」+ 为什么空 + 下一步出口，三档共用同一套口径。

这是初版方案，不是最终结论。 落地前还需要定：三段是三个还是四个（待办目前在桌面是独立一段）、 顶栏在移动端保留几块、进入时的初始态是展开还是收起， 以及「向上缩回」到底是就地收成一行还是滑出屏幕顶部。 详见 docs/modules/Menote-移动端界面稿-v1.md。
