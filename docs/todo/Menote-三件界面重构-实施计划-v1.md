## 一、批次与顺序

| 批 | 内容 | 为什么这个顺序 | 预估改动面 |
|---|---|---|---|
| **B1 设置页 A 批** | 死件接线（立即锁定 / 回收站）、注册到期关闭、隐私锁六卡、三处二次确认、12 处说明收 `InfoHint`、时区表、导航语义化 + owner 徽标 | **风险最低、用户观感提升最直接**；且这些项与分类重构同屏，先做能减少后一批的返工面 | `features/settings/**`、`app/ui/*`、`AccountQuickMenu.tsx`、契约 `settings.ts`（只改过时的 `pendingStep`） |
| **B2 笔记本分组 + 树设置** | 纯函数 `groupNotesByFolder` → 列表列分组 → 树里显示条目（契约 `notebook.show_items`）→ 树空态与入口 | 独立于设置页分类重构（只借用"通用"里一行，放在 B3 一起落）；列表列与树是同一屏，一起改一次测一次 | `features/notes/**`、`app.css`、`packages/shared/src/settings.ts` |
| **B3 Memo 侧栏与图册** | 模块清单 + 注册表 → 契约 `memo_view.sidebar` → 三个纯函数 → 六块 UI + 视图切换 → 图册取数与 `MemoFlow` → `onLocate` → 图标 → 窄屏 | 工作量最大、且要动**令牌与 DESIGN**（取值来源待拍板）；放最后是因为它最依赖本轮的结论与前面的组件语言 | `features/memos/**`、`tokens.css`、`app.css`、`app/ui/Icon.tsx`、契约 |
| **B4 设置页 B 批** | 11 类进导航（缺的四类不进）、页头统一、`.radioset` 统一、间距与文字链接收口、主操作整理；顺带落"笔记本树显示条目"那一行设置项 | 依赖 B1（同屏）、B2（新增设置项）；重构面最大，所以排在最后 | `features/settings/**`、`router.ts`、`app.css`、多个测试 |

每批都是**一个可上线单元**：做完即 `lint` / `typecheck` / 全量测试 + 真实浏览器点验 + CHANGELOG + 一个版本号（+0.0.1）+ 提交推送。

## 二、每批的验收点

**B1**：账户菜单里两个候选真的可用（点了去对应页面）；注册开关能设到期时间；隐私锁页六卡齐全且未启用时只显示①；登出/关闭隐私锁/重置隐私密码都有二次确认且文案含"影响范围 + 能否恢复"；设置页无平铺说明（除必须可见的四类）；时区可搜可选；owner 徽标在导航上。

**B2**：全部笔记下能看到「未分类」+ 各文件夹分组与计数；选中父夹能看到子夹二级分组；`show_items` 开关切换后树里出现/隐藏条目（上限 50 + 「还有 N 条…」），2000 篇下仍无可感卡顿（列表行的 memo 化不被破坏：沿用 `notes-list-memo.test.tsx` 的渲染次数断言）；两层限制与隐私门禁不被绕过。

**B3**：六块逐块与原型对值（概述三数、热力图 12×7 与图例、随机漫步、那年今日、日期、标签）；视图切换可用；图册能显示带图 Memo（宽高缺失取 `1/1`）且空态有出口；随机/那年今日/图册点卡能定位并高亮；把 `hidden`/`order` 写进本地设置后渲染立刻跟着变（GUI 归 B4）；窄屏照原型 1080px 规则；`css-cascade` / `style-coverage` / `layout-invariants` / `focus-visibility` 全绿。

**B4**：11 类里已实现的 7 类在导航上（缺的四类不进）、owner 徽标只对 owner 显示；页头统一成一条；设置页无原生 `<select>`、无 `label+checkbox` 开关、无内联 `style`、无刻度外裸值；每类最多一个主操作；相关测试同步更新。

## 三、风险与对策

| 风险 | 对策 |
|---|---|
| Memo 侧栏牵动**令牌与 DESIGN**（232px / 176px / 30px / 4 列 / 840px 与 DESIGN 对不上） | 稿里已列清取舍，**开工前拍板**；若照原型，先改 `tokens.css` + `DESIGN.md` 四处再写样式 |
| 列表列分组可能**打破行的 `memo` 化**（性能回归） | 分组结果 `useMemo`、行 props 保持原始值/稳定引用；沿用 `notes-list-memo.test.tsx` 的"字段 getter 计数"断言，先让它在新实现下仍然通过 |
| 设置页重构会**碰 5 个测试文件**（硬写分类名/候选数/遍历分类） | 每批改完就同步测试，不留到最后；`app-navigation.test.tsx` 的"每个分类都有出口"要保留 |
| 图册取数引入 Dexie 索引 = db 版本升级 | 本轮**不加索引、不升版本**（内存过滤）；真需要再单开一步 |
| 侧栏"可插拔"若做成"读设置即时生效"，可能踩到**旧客户端保存抹掉新配置** | 契约解析层做"未知 id 原样保留"（稿 §2.3 的三条纪律），并用例钉住 |
