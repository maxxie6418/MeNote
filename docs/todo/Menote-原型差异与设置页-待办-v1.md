## 四、待办：笔记本的"文件夹与文件树"（#2）——**已完成**（三件界面重构 B2 = v0.5.12：中间列分组 + `show_items` 树设置；空态引导与树形态的 A/B/C 抉择由该批设计稿承载）

**已核实的现状**：左侧功能栏的笔记本树**是有的**（`FolderTree.tsx`：两层、折叠三角、引导线、计数；本轮之前已加），但
- 只有**建过文件夹**才会出现任何节点（空账号下树是空的，也没有空态引导）；
- 中间列表列在「全部笔记」下是**扁平**的（`filterByView` 只按 `folder_id` 过滤，`NoteList` 无分组/无树）。

而原型里：**功能栏是文件夹树（只有文件夹、两层）**（`prototype/menote-prototype.html:850-890`），
**中间列是"选中那个文件夹的条目"扁平列表 + 头部显示文件夹名**（`notes-tables.html:631-644`）——
**原型并没有"文件夹 + 文件"的混合树**。

所以要先定这是哪一档（用户口径是"笔记本仍未出现文件夹和文件树"）：
- **A 树 + 空态引导**：保持原型形态，补"还没有文件夹"空态 + 更明显的「新建文件夹」入口 + 彩色文件夹图标；
- **B 中间列按文件夹分组**：在「全部笔记」下按 文件夹 → 子夹 → 笔记 分组（分组头 + 组内笔记），点文件夹仍可过滤；
- **C Obsidian 式文件树**：中间列整体换成 文件夹/笔记 混合树（缩进 + 折叠），改动最大、与原型形态不一致。
