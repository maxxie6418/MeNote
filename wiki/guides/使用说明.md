# 使用说明（给家里人看）

| 项 | 值 |
|---|---|
| 适用范围 | Menote 的日常使用。**不需要会编程**——照着做即可 |
| 权威级别 | 模块规则。功能与规则以 `wiki/Menote-设计文档-v7.4.md` 为准，本文只讲"日常怎么用" |
| 最后更新日期 | 2026-10-03 |

> **这份文档有一处必须先说清楚的事**：Menote 把内容存在你自己的一台 Cloudflare 服务器上，**不是**在别人的服务器上。你的内容在服务器上**是明文存放的**——「加密空间」保护的是**别人打开你的网页时看不到**，不是"服务器硬盘上的数据已加密"。想看 §六 讲明白了再往下。

---

## 一、第一次用

1. 管理员（家里的第一位使用者）打开网站 → **注册**。**第一个注册的账号自动是管理员**，只有管理员能管实例设置。
2. 其他人要用，得管理员**在设置里打开注册**（管理页面 → 注册开关），然后各自注册。注册开关可以随时关掉，也可以设个"到某天自动关闭"。
3. 登录密码是**你设的登录密码**。它和"隐私密码"是两回事，别搞混（§六）。

## 二、三种内容怎么记

| 想记什么 | 用哪个 | 怎么用 |
|---|---|---|
| 长一点的文章、笔记 | **笔记** | Markdown 编辑器，支持标题、列表、代码块、表格语法 |
| 清单、对比、统计（多维表） | **表格** | 十种字段类型（文字 / 数字 / 单选 / 多选 / 勾选 / 状态 / 网址 / 图片 / 日期 / 标签），行可以拖动排序 |
| 随手一记、想到什么写什么 | **Memo** | 时间轴上的一小段话 |
| 待办、任务 | **待办** | **它其实是 Memo 打了标记**，不是另一种数据。想把某条 Memo 变成待办，给它加个标记就行 |

**这四种都是从 Markdown 长出来的**。所以任何时候你都能把全部内容导出成 `.md` 文件，用任何文本编辑器打开、被别的软件读走。这是"数据在自己手里"最实在的意思。

## 三、保存与多设备

- **不用点保存**。打字时自动保存（停手 2 秒左右、大文档最多 60 秒）。顶栏能看到同步状态。
- **离线也能写**。没网的时候照常用，写的内容先进本机队列，联网后自动补传。
- **多设备同时改同一篇会产生冲突**，系统**不会静默覆盖**——它会生成一份"冲突副本"让你自己决定留哪份。
- 正文超过 **2 MB** 会存不进去，提示拆分；单个附件最大 **20 MB**。

## 四、隐私锁到底做了什么（**这一节请认真看**）

Menote 有"加密空间"和"单篇加密"两个功能。**它们的作用是：当别人用你的电脑、或在你没解锁时打开你的网页，看不到这些内容。**

| 要点 | 说明 |
|---|---|
| 内容在服务器上**是明文的** | 这一点必须如实说。**不要**理解为"服务器上已加密" |
| 钥匙只在你的浏览器里 | 从来不上传服务器 |
| **忘记隐私密码 = 这些内容永久打不开** | 服务端没有钥匙、没有后门、也**没有找回途径**。设置里的"重置隐私密码"会作废旧钥匙，让这些内容从此无法解开 |
| 锁不锁**不影响**你能不能搜到、能不能导出 | 锁着的只是"别人打开页面时看不看得到" |

**什么时候该开、什么时候不必开**：这台服务器是你自己的，内容也确实只有家里几个人写，那么开锁带来的主要收益是"防止别人偶然看到"。它的代价是**忘了就永久丢失**。这是你的选择。

## 五、备份与导出

| 方式 | 怎么做 | 适合什么时候 |
|---|---|---|
| 导出单篇 | 笔记「更多」菜单 → 导出 | 只想拿走某一篇 |
| **导出全部** | 设置 › 备份与导出 → 导出 zip | **推荐定期做**。得到一个包含全部 md、附件、草稿的压缩包 |
| 分享链接 | 笔记「更多」菜单 → 分享 | 给别人看某一篇。对方只能只读，看不到你其他任何内容 |
| 外部备份（WebDAV / S3） | 设置 › 备份与导出（**M7 正在做，暂不可用**） | 想让服务器挂了也有第二份 |

**分享链接什么时候会失效**：设了有效期、到期了；你撤销了；这篇被删掉或进了回收站；这篇被加密了。**注意**：链接带密码也挡不住认识密码的人，而链接本身在聊天记录和截图里是会被人看到的。

## 六、密码

| 名称 | 作用 | 忘了怎么办 |
|---|---|---|
| **登录密码** | 登录账号 | 管理员可以帮你重置；改密码会让**其它设备全部退出登录**（当前设备保留） |
| **隐私密码** | 解锁加密空间 / 单篇加密的内容 | **没有找回途径**。只能重置，但重置意味着旧内容永久无法解开 |

**这两个密码互不相通**，别混用。设的时候也别设成一样的。

## 七、回收站与版本历史

- 删掉的东西先进**回收站**，默认 30 天后永久删除（天数可在设置里改）。**回收站里的东西还在**。
- 每篇笔记的改动会自动留下**版本**。改错了或者 AI 改坏了，可以在版本历史里**撤回**。
- 版本保留策略：每篇约 50 个、全部加起来约 2000 个，太旧的会被自动清理。所以**重要的东西请自己导出一份**。

## 八、MCP（让 AI 读写你的笔记）

设置 › MCP 里可以创建**令牌**，把它和网站地址一起交给 Cursor、Claude Code 这类工具，它们就能搜索、读、写你的笔记。

**开之前想清楚三件事**：

1. **令牌 = 一把钥匙**。给了谁，谁就能用他的身份读写你的内容。**别给不认识的人的 agent**。
2. **默认建议只读**。勾了「修改和移动」或「移到回收站」之后，那个工具就能改你的笔记、甚至删进回收站。
3. **只记写操作**。设置 › MCP › 审计记录里能看到这枚令牌改过什么、什么时候改的。**定期看一眼**，不对就立刻撤销（撤销立刻生效）。
4. **隐私内容看不见**。加密空间里的东西，MCP 一律读不到——这条与令牌配置无关。

## 九、日常容易踩的三个坑

1. **用 `http://` 打开网站会注册不了、保存不了**。浏览器只在安全上下文（`https://` 或 `localhost`）提供加密能力。部署时打开 Cloudflare 的 **Always Use HTTPS** 就能避免。
2. **顶栏一直显示"同步中"**：多半是没网。内容不会丢，联网后自动补。
3. **内容"不见了"**：先看**回收站**（默认 30 天保留），再看**版本历史**。都找不到，说明当时真没保存成功。
